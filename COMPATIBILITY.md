# Совместимость и ограничения NetDeck

## macOS 2.0.8 (208)

- Основное приложение и Core содержат архитектуры Apple Silicon (arm64) и Intel (x86_64). Работа на физическом Intel Mac в рамках подготовки этого выпуска не проверялась.
- Требования отдельных встроенных компонентов отличаются: некоторые USB/backup-компоненты arm64 требуют macOS 26 или новее. Наличие универсального основного приложения не означает поддержку всех операций на любой версии macOS.
- Создание зашифрованной резервной копии может завершиться ошибкой 255. Успешная проверка структуры копии не равна проверенному восстановлению устройства.
- Подпись приложения локальная ad-hoc, без Developer ID и нотариального заверения Apple. macOS может показать предупреждение Gatekeeper. Подпись архива обновления Sparkle проверяется отдельно и не заменяет нотариальное заверение.
- При каждом запуске требуется новый вход в Apple ID с паролем; двухфакторное подтверждение запрашивается по требованию Apple.

При подготовке 2.0.8 проверялись локальные тесты и интерфейс на изолированных данных в обеих темах. Реальные Apple ID/2FA, скачивание и установка IPA, USB и резервное копирование в этой итерации не проверялись. Подробности сохранены на [странице выпуска](https://github.com/andruha2618/NetDeck/releases/tag/v2.0.8).

## Windows

Публично доступна версия [Rift Manager 2.0.4 (204) x64](https://github.com/andruha2618/NetDeck/releases/tag/windows-v2.0.4). Она сохраняет прежнее название и интерфейс; её возможности и состояние авторизации отличаются от текущей macOS-версии. Новая Windows-сборка с переносом авторизации находится на отдельной проверке и пока не опубликована.

Для подключения iPhone по USB нужны драйверы Apple. Переносную версию распаковывайте целиком: один EXE без соседних библиотек не является полной установкой.

## Обновления и старые установки

В macOS используется подписанный [канал Sparkle](https://raw.githubusercontent.com/andruha2618/NetDeck/main/appcast-macos.xml). Пакеты проверяются существующим ключом Ed25519. После обновления старой установки имя на диске может остаться `Rift Manager.app`, хотя внутри приложение называется NetDeck.

В Windows сохранён отдельный [канал обновлений](https://raw.githubusercontent.com/andruha2618/NetDeck/main/appcast-windows.xml). Выпуски macOS и Windows не взаимозаменяемы.
