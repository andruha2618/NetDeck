# NetDeck

**Управление iPhone и iPad с компьютера.**

NetDeck разработан, чтобы собрать повседневную работу с устройствами Apple в одном приложении: просматривать сведения об устройстве, управлять приложениями и IPA, переносить файлы и работать с локальными резервными копиями.

[Скачать для macOS](https://github.com/andruha2618/NetDeck/releases/latest) · [Скачать для Windows](https://github.com/andruha2618/NetDeck/releases/tag/windows-v2.0.4) · [Все выпуски](https://github.com/andruha2618/NetDeck/releases) · [Сообщить об ошибке](https://github.com/andruha2618/NetDeck/issues/new)

## Возможности

- **Обзор устройства.** Модель, версия iOS, заряд аккумулятора, занятое хранилище и установленные приложения.
- **Приложения и IPA.** Работа с библиотекой приложений, вход в Apple ID, просмотр доступных аккаунту покупок, загрузка и установка IPA.
- **Содержимое устройства.** Просмотр и перенос доступных приложению файлов, фотографий и видео.
- **Загрузки.** Очередь операций, фактический прогресс и история загрузок.
- **Резервные копии.** Создание локальных копий, управление ими и восстановление устройства.
- **Настройки и диагностика.** Светлая и тёмная темы, выбор папок хранения, проверка обновлений и журнал работы.

Возможности зависят от версии приложения, системы, подключённого устройства и разрешений Apple. Функции App Store используют вашу учётную запись; NetDeck не предоставляет права на чужие покупки и не снимает ограничения лицензий.

### macOS

1. Закройте предыдущую версию приложения.
2. Откройте DMG и перенесите `NetDeck.app` в папку «Программы».
3. Для работы с устройством подключите его, разблокируйте и подтвердите доверие к компьютеру.

При переходе с Rift Manager существующие настройки сохраняются. Для функций Apple ID в версии 2.0.9 нужен новый вход при каждом запуске; код подтверждения запрашивается по требованию Apple.

### Windows

Запустите установщик либо полностью распакуйте переносную версию и откройте `Rift Manager.exe`. Для USB-подключения нужны драйверы Apple. Опубликованная Windows-версия сохраняет прежние название и интерфейс; новые сборки публикуются после отдельной проверки.

Требования, особенности подписи macOS и известные ограничения резервного копирования описаны в [совместимости](COMPATIBILITY.md). Для каждого выпуска доступны контрольные суммы в `SHA256SUMS.txt`.
